# Tiny Farm 2 (GBA)

Controls: D-pad move, A use tool / talk / sell / buy / sleep (at your door after noon),
B or R next tool, L previous tool, SELECT changes seed type (turnip / potato / pumpkin).
Hold SELECT while booting to ignore the save and start fresh.

Build:  make          (needs arm-none-eabi-gcc; or use the GitHub Action in .github/)
Output: tinyfarm.gba  (use gbafix on it for real hardware)
